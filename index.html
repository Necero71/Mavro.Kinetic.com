Services

  • Websites

    Hand-coded HTML, CSS and JavaScript, built phone-first and tested on real devices. No page builders, no heavy frameworks, and it runs on free static hosting so there is no server bill.

  • Branding

    A logo, colour palette and type choices, pulled together in a one-page brand sheet. Made to hold up on a website, a sticker and a social avatar.

  • Web apps and tools

    Small installable apps that keep working with no signal. Calculators, trackers and booking helpers, written in plain JavaScript. MK NAVKIT, below, is one.

  • Site tune-ups

    Already have a page? Fix what is slow, broken or awkward on a phone: faster loading, clearer buttons, better search previews, without a full rebuild.

Selected work

FYR_SPEEDZ

A booking site for a Cape Town auto electrical and diagnostics business with mobile service. The goal: get a customer from the page to a WhatsApp message in one tap.

  • Every service opens a pop-up with a pre-written WhatsApp enquiry
  • Call and WhatsApp buttons stay within thumb reach
  • Search and share previews set up for the business

MK NAVKIT

A field companion for Arma Reforger players on Xbox, built to sit on a phone next to the console. Install it once and it works with no signal.

  • Mil range estimator, grid-to-grid distance and bearing
  • Plot a contact, pace count with travel times, personal range card
  • Installs to the home screen and runs offline

MK PITWALL

Pre-alpha

An F1 26 setup book for your phone or tablet. Keep a setup for each track and condition instead of hunting through notes. Early build, still changing.

  • Setup sheet with quick steppers, saved per track and conditions
  • Compare any two setups side by side, with a symptom guide for handling problems
  • Installs to the home screen, runs offline, with export and import for backups

How a project runs

  1. Brief

    You describe what the site needs to do and who it is for. The form below takes about two minutes.

  2. Design

    Colours, type and layout are settled first, as a short plan you approve before any code is written.

  3. Build

    Hand-coded, then tested on a phone and in a desktop browser before you see it.

  4. Launch

    Published on fast static hosting, with the files handed over so the site is yours.
