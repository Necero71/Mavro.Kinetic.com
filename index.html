How a project runs

  1. Brief

    You describe what the site needs to do and who it is for. The form below takes about two minutes.

  2. Design

    Colours, type and layout are settled first, as a short plan you approve before any code is written.

  3. Build

    Hand-coded, then tested on a phone and in a desktop browser before you see it.

  4. Launch

    Published on fast static hosting, with the files handed over so the site is yours.
